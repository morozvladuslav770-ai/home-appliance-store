# Фото демонстраційних товарів

Покладіть фото в папки з номерами товарів, а потім виконайте в `backend`:

```bash
bin/rails db:seed                # якщо ще не робили: створює товари
bin/rails products:import_photos # додає фото з цих папок
```

Команду можна запускати повторно: товари, які вже мають фото, пропускаються.
Щоб замінити наявні фото, додайте `FORCE=1`: `FORCE=1 bin/rails products:import_photos`.

## Як це організувати

Для кожного товару створіть папку з його номером і покладіть туди 1–8 зображень:

```
db/seed_photos/
├── 01/
│   ├── 1.jpg      <- перше за алфавітом файл стане головним фото
│   ├── 2.jpg
│   └── 3.jpg
├── 02/
│   └── front.png
└── …
```

Формати: JPG, PNG, WebP; не більше 5 МБ кожне; не більше 8 фото на товар.
Головним фото стає перший файл за назвою, тому називайте їх `1.jpg`, `2.jpg`, …

## Де взяти фото

Беріть лише зображення, які можна вільно використовувати:

- власні фотографії;
- безкоштовні стоки з відкритою ліцензією (Unsplash, Pexels, Pixabay): перевіряйте умови ліцензії на сторінці фото;
- Wikimedia Commons (фото з ліцензією CC: вкажіть автора, якщо вимагає ліцензія);
- пресматеріали виробників, лише якщо їхні умови дозволяють таке використання.

Не завантажуйте фото з чужих інтернет-магазинів: вони захищені авторським правом.

Фото можна також додавати вручну в адмін-панелі: «Товари» → «Редагувати» → «Додати фото».
